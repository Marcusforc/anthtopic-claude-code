# CCTV Pro (iOS)

Приложение для монтажников систем видеонаблюдения: объекты, калькуляторы и сметы. SwiftUI + SwiftData, iOS 17+, тёмная тема.

## Экраны

- **Объекты** — список со статистикой, поиском и фильтром по статусу; создание и удаление (долгое нажатие).
- **Карточка объекта** — обложка, контакты, камеры, кабель, оборудование, фото, заметки, смета, редактирование.
- **Калькуляторы** — HDD (объём архива), PoE-бюджет, блок питания 12 В, падение напряжения на кабеле, Wi-Fi.
- **Сметы** — итого по оборудованию и работам, экспорт в PDF, отправка текстом.
- **Профиль** — данные исполнителя.

Формулы калькуляторов — в `Sources/Calculators/Calculators.swift` (без UI, покрыты тестами). Все они ориентировочные.

## Сборка

Нужны macOS, Xcode 15+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```sh
brew install xcodegen
cd ios/CCTVPro
xcodegen          # создаст CCTVPro.xcodeproj
open CCTVPro.xcodeproj
```

Тесты: `Cmd+U` в Xcode. В Debug-сборке при первом запуске добавляются демо-объекты (`SeedData`).

# Голосовое управление Google Sheets

Статическое веб-приложение без бэкенда: речь (Web Speech API, `ru-RU`) → парсер команд → Google Sheets API v4.
Нужен Chrome или Edge.

## Запуск

1. В Google Cloud Console включите **Google Sheets API** и создайте **OAuth Client ID** (тип Web application).
   В Authorized JavaScript origins добавьте `http://localhost:8080`.
2. `npm start` и откройте http://localhost:8080
3. Вставьте Client ID и ссылку на таблицу, нажмите «Войти в Google», затем «Говорить».
   Команды можно вводить и текстом.

## Команды

| Что сказать | Действие |
|---|---|
| «Запиши 500 в ячейку B3», «В B3 запиши привет» | запись значения (формулы тоже: «=A1*2») |
| «Прочитай ячейку B3», «Покажи A1 до C5» | чтение, ответ озвучивается |
| «Добавь строку: Иван, 25, Москва» | добавление строки в конец |
| «Сумма A1 до A10 в ячейку C1» | запись формулы (SUM, AVERAGE, MAX, MIN, COUNT) |
| «Среднее A1 до A10» | расчёт без записи |
| «Очисти A1 до C5» | очистка диапазона |
| «Жирным A1 до C1» | жирный шрифт |
| «Новый лист Расходы», «Перейди на лист Расходы» | работа с листами |
| «Отмени» | откат последних записи, очистки, строки |

Названия столбцов можно произносить по-русски: «бэ 3», «цэ 12», «эф 1» (A–H); остальные — латиницей.

## Тесты

`npm test` — тесты парсера команд (`node:test`, без зависимостей).

## Ограничения

- Числа словами («пятьсот») не распознаются, говорите цифрами; распознавание обычно подставляет их само.
- Отмена хранится только в памяти страницы; форматирование и листы не откатываются.
